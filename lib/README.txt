Put the SQLite JDBC driver jar in this folder.

1. Open https://mvnrepository.com/artifact/org.xerial/sqlite-jdbc
2. Choose the latest version, click the "jar" link, and save it here (name looks like sqlite-jdbc-3.xx.x.jar)
3. If you later see an error mentioning SLF4J, also download slf4j-api (2.x) from
   https://mvnrepository.com/artifact/org.slf4j/slf4j-api and put that jar here too.
4. In VS Code, reload the window (Ctrl+Shift+P -> "Developer: Reload Window") so it detects the jar.
